Acme Corp — an external website on a different origin

Serve this folder with python -m http.server 8080 (from demo/) and open http://localhost:8080/external_site.html?t=YOUR_TOKEN. Optional: &host=http://127.0.0.1:8000 (default) to point at the assistant server.

Add ?t=YOUR_TOKEN to the URL (copy the token from the dashboard's Assistant page).

Variant 1: iframe

Variant 2: floating button

The <script src=".../embed.js?t=…"> tag adds the chat button in the bottom-right corner.
